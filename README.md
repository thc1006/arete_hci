# 百川112適用畢業預審表：系辦工作流程與HCI資料包

日期：2026-09-08。

## 開啟方式

用桌面瀏覽器開啟 `系辦預審互動原型.html`。不需要安裝後端，也不需要登入。HTML包含原始範本的兩張渲染圖；操作本身不會連線。只有主動點官方來源連結才會開啟外部網站。

操作順序：工作清單 → 收件與辨識 → 勾選合成資料範圍 → 逐列核對。可試英文3→2學分更正、線性代數重複填列、◎條件試算、通識轉列、伦理補件、停修更新、研究所預留影響，以及匯出示範JSON。

**所有學生/成績/課程認列案例是合成資料，不代表本校正式認定。重整將清空操作。**

## 檔案

- `系辦預審互動原型.html`：可點選的單檔前端。
- `WORKFLOW_HCI_SPEC.md`：原表分析、工作流程、畫面、資料契約、權限、驗收規格。
- `field_map_112.json`：20個區段/欄位規則及原格定位。
- `workbook_cells.json`：原始附件170個非空儲存格內容。
- `workbook_structure.json`：合併區、隱藏列、結構與原檔雜湊。
- `sources.json`：原始附件及12筆官方/第一手網路參考資料。
- `demo_cases.json`：8個合成示範列，非全案。
- `original_top.png`、`original_bottom.png`：未修改原始表的渲染，用於版型檢查。
- `介面預覽_逐列核對.png`、`介面預覽_結果與補件.png`、`介面預覽_窄視窗.png`：Chromium實際操作截圖。
- `test_prototype.py`、`prototype_test_results.json`：24項已執行通過的合成UI檢查。
- `sample_sealed_demo.json`：测试產生的局部示範核對快照，非正式簽章。
